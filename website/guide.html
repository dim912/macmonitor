Installation

MacMonitor is designed to be easy to install with minimal dependencies. Choose your preferred installation method:

Option 1: Homebrew (Recommended)

Using Homebrew is the easiest way to install and maintain MacMonitor:

brew tap username/macmonitor
brew install macmonitor

Option 2: One-Line Installer

If you don't have Homebrew, you can use our one-line installer script:

bash -c "$(curl -fsSL https://raw.githubusercontent.com/user/mac-system-monitor/main/install_curl.sh)"

Option 3: Manual Installation

To manually install:

  1. Download the latest release from the GitHub repository
  2. Extract the archive to any location
  3. Open Terminal and navigate to the extracted directory
  4. Run chmod +x install_monitor.sh to make the installer executable
  5. Run ./install_monitor.sh to install

Note: MacMonitor requires macOS 10.13 (High Sierra) or later. For older versions, please use MacMonitor Legacy from our GitHub repository.

Quick Start

After installation, MacMonitor automatically starts monitoring your system in the background. Here's how to quickly start using it:

View Your Stats

Open Terminal and run:

mm show

This will display your system stats with auto-refresh every 30 seconds.

Access Help

For a list of all available commands:

mm help

That's it! MacMonitor is running and will notify you of any issues with your system metrics.

Understanding Metrics

MacMonitor tracks several key metrics about your Mac's health:

Metric Normal Range What to Watch For
CPU Temperature 30-80°C Values over 85°C indicate high processor load and potential thermal throttling.
GPU Temperature 30-80°C Values over 85°C indicate graphics processing stress.
WindowServer CPU 1-20% Values over 50% can indicate UI issues or graphics driver problems.
Memory Pressure Normal/70-85% "Warning" or "Critical" status indicates system is running low on memory.
Swap Usage 0-100MB Values over 500MB indicate memory pressure and potential performance issues.
Fan Speed 1000-3000 RPM Values over 5000 RPM indicate the system is working hard to cool components.

Tip: Some metrics might show N/A depending on your Mac model. Not all Macs expose all sensor data.

Alert System

MacMonitor will display alerts in the rightmost column of the monitoring display when metrics exceed their thresholds. The alert format provides detailed information about the issue:

| 2025-04-06 20:51:53 | 60 | 65 | 15 | 71% | 145.25M | 4722 | 6:00 | [SWAP 145.25M/1MB +14425%] |

The alert format [TYPE current/threshold +percentage] tells you:

  • TYPE: Which metric has exceeded its threshold (CPU, GPU, SWAP, etc.)
  • current/threshold: The current value and the threshold value
  • +percentage: How much the current value exceeds the threshold by percentage

When alerts are triggered, you'll also receive macOS notifications. For memory alerts, MacMonitor logs details about top memory-consuming applications to:

~/monitor_logs/alerts/memory_alerts_$(date +%Y-%m-%d).log

Alert Management

MacMonitor includes several features to help manage alerts and avoid notification fatigue:

Severity Levels

Alerts are categorized by severity based on how far they exceed thresholds:

  • 🟡 Low: Minor threshold exceedance
  • 🟠 Medium: Moderate threshold exceedance
  • 🔴 High: Significant threshold exceedance

Alert Cooldown

Once an alert for a metric is shown, it won't trigger again for the set cooldown period (default: 10 minutes), preventing repeated notifications for the same issue.

Do Not Disturb Mode

Schedule quiet hours when no alerts will appear, perfect for presentations, meetings, or nighttime.

Alert Aggregation

Multiple alerts are combined into a single notification, reducing the number of interruptions.

Smart Thresholds

The system can learn what's normal for your Mac over time and adapt thresholds accordingly (optional feature).

Reduced Sound Alerts

Configurable number of beeps per alert (default: 2 beeps, down from the original 10).

Customization

MacMonitor is highly customizable to suit your specific needs. Use the mm config command to customize thresholds and alert behaviors:

Viewing Current Settings

mm config list

Setting Alert Thresholds

mm config set cpu 80

Set CPU temperature threshold to 80°C

mm config set gpu 80

Set GPU temperature threshold to 80°C

mm config set wscpu 40

Set WindowServer CPU usage threshold to 40%

mm config set swap 1000

Set swap usage threshold to 1000MB

mm config set fan 6000

Set fan speed threshold to 6000 RPM

mm config set memory 85

Set memory pressure threshold to 85%

mm config set streak 2

Alert after 2 consecutive readings (default: 3)

Alert Management Settings

mm config set beeps 1

Set alert beep count to 1 (0-10)

mm config set cooldown 5

Set cooldown period to 5 minutes (1-60)

mm config set severity 1

Set minimum severity level (1=Low, 2=Medium, 3=High)

Do Not Disturb Settings

mm config set dnd on

Enable Do Not Disturb mode (on/off)

mm config set dnd-start 22:00

Set DND start time (24-hour format)

mm config set dnd-end 07:00

Set DND end time (24-hour format)

Smart Thresholds

mm config set smart on

Enable smart adaptive thresholds (on/off)

Reset All Settings

mm config reset

Daily Usage

Checking Current System Status

mm show

Show real-time system stats with auto-update

mm show -l 100

Show 100 most recent entries (default: 20)

Advanced Usage

cat ~/monitor_logs/dual_monitor_log_$(date +%Y-%m-%d).txt

View today's complete log file

grep "$(date +%Y-%m-%d\ %H)" ~/monitor_logs/dual_monitor_log_$(date +%Y-%m-%d).txt | grep "\["

Check if any alerts happened in the last hour

cat ~/monitor_logs/alerts/memory_alerts_$(date +%Y-%m-%d).log

View memory alerts from today

Pro Tip: Add these aliases to your .bashrc or .zshrc file for quick access:

alias monitor-stats='mm show'
alias monitor-alerts='grep "\[" ~/monitor_logs/dual_monitor_log_$(date +%Y-%m-%d).txt'

Troubleshooting

Missing Values (N/A)

If you see N/A for certain metrics, it might be because:

  • Your Mac model doesn't expose those metrics
  • Required dependencies are missing

Run the test command to check what's available on your system:

mm test

Service Not Running

If monitoring stops, check if the service is running:

launchctl list | grep monitorlogger

If not found, restart the service:

mm restart

Viewing Error Logs

If you're experiencing issues, check the error logs:

cat /tmp/monitorlogger.err

Frequently Asked Questions

How does MacMonitor affect battery life?

MacMonitor is designed to be extremely lightweight. It only checks system metrics every 30 seconds by default, using minimal CPU and negligible amounts of memory. The impact on battery life is typically less than 1%.

Can I change the monitoring interval?

Yes. Edit ~/.monitor/monitor_status.sh and change the INTERVAL=30 value to your preferred seconds, then run mm restart.

Why can't I see GPU temperature?

GPU temperature requires special permissions. During installation, you should have been asked to set up GPU monitoring. If you skipped it, run the installer again: ./install_monitor.sh and answer "y" to the GPU setup question.

How do I completely uninstall MacMonitor?

Run the uninstall command:

mm uninstall

This will stop the monitoring service, remove the startup agent, and clean up files. Your logs will remain in ~/monitor_logs until you manually delete them.

Does MacMonitor work with Apple Silicon Macs?

Yes! MacMonitor is fully compatible with both Intel and Apple Silicon Macs. Temperature monitoring features work on all M1/M2/M3 series chips.
