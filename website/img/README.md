# Image Assets for MacMonitor Website

This directory should contain the following image assets:

## Logo Files
- `logo.svg` - Main color logo for light backgrounds
- `logo-white.svg` - White version of logo for dark backgrounds
- `favicon.png` - Favicon for browser tabs

## Content Images
- `dashboard.png` - Screenshot of MacMonitor dashboard
- `social-preview.jpg` - Preview image for social media sharing

## Create SVG logos with the following specifications:

### logo.svg
A simple logo showing a monitor with a graph line, using indigo color (#4F46E5) as the primary color.

### logo-white.svg
The same design as logo.svg but with white (#FFFFFF) as the primary color.

### Favicon
A simplified version of the logo, optimized for small display in browser tabs.

## Image Optimization

All images should be optimized for web:
- PNG files should be compressed
- JPG files should be optimized to balance quality and file size
- SVG files should have unnecessary metadata removed

## Usage Guidelines

- Use the color logo on light backgrounds
- Use the white logo on dark backgrounds (like the footer)
- Ensure proper alt text is used for all images in HTML
