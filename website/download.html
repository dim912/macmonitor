Install MacMonitor

Get started with the lightweight monitoring tool for your Mac

Choose Your Installation Method

Option 1: Homebrew (Recommended)

The easiest way to install and keep MacMonitor updated. If you already have Homebrew installed, this is just two simple commands:

brew tap dim912/tap
brew install macmonitor

Note: Don't have Homebrew? Install it first, then come back to run the commands above.

Automatic updates via brew upgrade

Option 2: One-Line Installer

Quick installation without Homebrew. Just paste this command in Terminal:

bash -c "$(curl -fsSL https://raw.githubusercontent.com/dim912/macmonitor/main/install_curl.sh)"
Works with any macOS 10.13 or later

Option 3: Manual Download

Download the latest release and install manually. Great for offline installation or custom setups.

Download Latest Release

Installation steps:

  1. Extract the downloaded ZIP file
  2. Open Terminal and navigate to the extracted directory
  3. Run chmod +x install_monitor.sh to make the installer executable
  4. Run ./install_monitor.sh to install
Complete control over installation process

System Requirements

  • Operating System: macOS 10.13 (High Sierra) or later
  • Processor: Any Intel or Apple Silicon Mac
  • Disk Space: < 5MB
  • Memory: Minimal (< 10MB)
  • Special Permissions: Admin rights (only for installation)
  • Dependencies: Will be installed automatically
